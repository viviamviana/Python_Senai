# Python_Senai
Repositório com exercícios e atividades desenvolvidos durante o curso livre de **Programação em Python**, realizado pelo **SENAI**.

O curso teve como objetivo desenvolver a lógica de programação e apresentar fundamentos da linguagem Python por meio de exercícios práticos.

## 📚 Conteúdos abordados
* Fundamentos do Python
* Lógica de programação
* Manipulação de strings
* Estruturas condicionais
* Estruturas de repetições
* Listas
* Tuplas
* Dicionários
* Funções
* Manipulação de arquivos
* Resolução de desafios

## 💻 Tecnologias
* Python
* Jupyter Notebook

## 🎯 Objetivo
Este repositório representa uma etapa da minha formação em programação, com foco no desenvolvimento da **lógica de programação** e na construção de uma base nos **fundamentos da linguagem Python**.

## 📌 Observação
Os códigos foram desenvolvidos durante o curso e posteriormente revisados para corrigir erros, simplificar algumas explicações e melhorar a organização do conteúdo.

Por se tratar de um material de aprendizado, alguns exercícios podem apresentar diferentes abordagens para a resolução do mesmo problema, refletindo meu processo de aprendizado.
